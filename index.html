Alza Mailbot

An email-based AI customer-support assistant — a technical demo project.

What it does

Alza Mailbot watches one dedicated Gmail inbox. When a customer sends an email there, the bot reads the message (including PDF, image and audio attachments), generates an answer with a large language model, and replies within the original email thread — typically in under two minutes. Follow-up questions are answered with the whole conversation in context.

How it is built

Two services run on Google Cloud Run: an email processor (Gmail API, Pub/Sub push notifications, Firestore state) and a chatbot service (Vertex AI Gemini). The source code lives in the alza-mailbot GitHub organization.

Privacy

The bot accesses only its own dedicated mailbox and processes incoming messages solely to generate a reply. See the full privacy policy.
